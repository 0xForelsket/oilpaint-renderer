# Golden hashes

`golden/<engine-version>.json` records the SHA-256 of every `identical` cross-host case (`ci/xhost`) for one
engine version:

```json
{"engine": "2.0.0-dev.1", "hosts": ["native-windows-x86_64", "node-…", "chromium-…"], "cases": {"kernel.sheet@600.rgb": "…"}}
```

- They are **regression checks only**, generated by the new engine. They are not references against v1 or the C
  kernel, which have no goldens here.
- The first file appears with L1, when the engine has real output. L0's maths cases are compared across hosts
  but get no golden.
- `npm run xhost -- --write-golden` writes the file from a run in which every host agreed. It may add new cases,
  but it refuses to change an existing digest.
- **An output change needs an engine-version bump** (`oil_kernel::ENGINE_VERSION`), then a new golden file for
  the new version. Old golden files stay as a record.
- These files are stored byte-for-byte (`.gitattributes`).
